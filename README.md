# loose-coupling-practice

This repository was created to practice loose coupling in the system. 

## 사전 설명

현 작업은 코드를 작성하는 데 있어, 각 기능 별 종속 수준을 낮추는 설계를 연습한다는 목적을 지닙니다. 이에 따라 작업 대상이 될 파일이 필요하며, 그 대상은 개인 대학 과제 제출물 중 하나로 선정했습니다. 선정 이유는 간단한데, 과거에 작성한 코드이기에 완성도나 구조적인 측면에서 허술할 것으로 기대했기 때문입니다. 

## 작업 대상 코드 설명

### 기초 상황 설명

현 작업의 목표가 되는 코드는 **CheXpert dataset을 사용해 Muliti-label classification을 수행하는 딥러닝 모델을 구현 및 개선**을 목적으로 합니다. 따라서 현 작업의 목표 역시 동일하게 가져가야 합니다. 

당시 각 학생들에게 제공된 서버 환경은 GeForce RTX 4090 VRAM 24GB이며, 따라서 현 작업은 이를 넘어서는 하드웨어 사양을 요구하지 않아야 합니다. 

당시 서버 경로에 맞춰 path가 설정되어 있습니다. 따라서 해당 경로가 수정되어서는 안 됩니다. 이로 인해 서버를 사용할 수 없는 사람은 테스트 및 실제 구동이 불가능합니다. 이 문제를 완화하기 위해 필요할 때마다 자세한 설명을 첨부합니다. 

모델의 입력 값이 되는 CheXpert dataset은 서버에 이미 마련되어 있었습니다. 데이터 가공 흔적이 존재했기 때문에 실제 원본 데이터와 그 형태나 구성이 상이할 수 있습니다. 이 역시 상기한 같은 이유로 자세한 설명을 병기할 예정입니다. 

### 코드 구성 설명

코드는 크게 데이터 영역과 모델 영역, 그리고 학습 영역으로 구분됩니다. 

데이터 영역에서는 데이터를 읽고, 적절히 가공하여 모델에 입력할 수 있도록 마련하는 과정을 담당합니다. 여느 데이터가 그렇듯 데이터 가공이 가장 중요하게 다뤄집니다. 

모델 영역은 모델 아키텍처를 정의하개 됩니다. 모델을 완전히 새롭게 구성하지는 않으며, `torchvision`에서 제공되는 pre-trained model을 중심으로 fine-tuning합니다. 각 사전 학습 모델은 cheXprt와 다른 데이터로 학습되었기에, 자연스럽게 모델의 classifier 영역이 새롭게 구성됩니다. 

학습 영역은 가공된 데이터와 마련된 모델을 통해 모델 학습 및 하이퍼 파라미터 튜닝을 목적으로 삼습니다. 기본적으로 모델의 파라미터를 저장하고 불러오는 방식을 사용합니다. cheXpert에는 Blank와 Uncertain이라는, 정보가 불확실한 레이블이 존재하기 때문에 이를 고려하여 모델의 손실값 계산 등이 반영됩니다. 이는 데이터 설명에서 다루겠습니다.
